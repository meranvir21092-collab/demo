# Practical 2: Study of Login and Logout Details

## Aim
To study user login/logout and session details.

## Commands
```bash
who          # users logged in
whoami       # current username
id           # user and group IDs
tty          # terminal name
w            # users and their activity
last         # recent login records, if available
logout       # exit a login shell (may not work in every terminal)
exit         # exit the current shell
```

## Notes
- `who` displays active login sessions.
- `whoami` prints the effective username.
- `last` reads login history, usually from system accounting files.
- In a graphical terminal, use `exit` or close the terminal; `logout` may report that it is not a login shell.

## Result
Login and session information was inspected using standard commands.
