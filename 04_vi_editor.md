# Practical 4: Study of the vi Editor

## Aim
To create and edit a text file using `vi`/`vim`.

## Commands
```bash
vi lab.txt
```
- Press `i` to enter Insert mode.
- Type the text.
- Press `Esc` to return to Normal mode.
- Type `:w` and press Enter to save.
- Type `:q` and press Enter to quit.
- Use `:wq` to save and quit.
- Use `:q!` to quit without saving.
- In Normal mode, `dd` deletes a line, `yy` copies a line, and `p` pastes after the cursor.
- `/word` searches for `word`; press `n` for the next match.

## Result
A file was created and edited using the vi editor.
